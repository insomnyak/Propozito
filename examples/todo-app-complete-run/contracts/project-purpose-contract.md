# Project Purpose Contract

## Project

Simple To-Do Application

## Purpose

Provide a minimal task list that lets a user add, view, complete, and delete to-do items.

## Target Users

- first-time user
- non-technical user
- keyboard-only user

## Non-Goals

- accounts
- synchronization
- notifications
- multi-device persistence

## Success Criteria

- users can create a task with visible text
- users can mark a task complete
- users can delete a task
- empty task text is rejected

## Unacceptable Shortcuts

- marking the feature complete without tests
- accepting empty task titles
- hiding failed commands
