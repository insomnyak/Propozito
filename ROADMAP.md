# Roadmap

## v0.1 Alpha

- Canonical policies, schemas, gates, validators, and worked example.
- Portable skill metadata constrained to `name` and `description`.
- Initial task decomposition and evidence validation workflow.

## v0.2.0 Beta

- Setup contract, terminology profile, user interaction profile, and autonomy profile.
- Project Control Room, Verification Center, placeholder ledger, and signoff integrity contracts.
- Deterministic application relationship graph, implementation map, impact check, and optional semantic memory index contract.
- Prompt refinement, prompt history, context rotation, rework register, state lifecycle, boundary, capability-surface, and evidence storage policies.
- Generic beta graph-aware example and validators.

## v0.3 Adapters

- Harden ChatGPT/Codex, Claude, Qwen Code, and Kimi Code adapters.
- Add adapter-specific examples without changing the canonical standard.

## v0.4 CLI Scaffolder

- Generate `.ai-state/`, contracts, ledgers, traceability records, and gate stubs.
- Run validators as a single command.

## v0.5 Field Testing

- Add real project case studies.
- Refine gates based on failures observed in real repositories.

## v1.0 Stable Spec

- Freeze core schema contracts after field testing.
- Publish compatibility guarantees for validators and adapters.
