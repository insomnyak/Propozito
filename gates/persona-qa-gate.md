# Persona QA Gate

Gate ID: `persona-qa`

## Purpose

Verify that the implementation works for target user goals, not only for developer assumptions.

## Checks

- persona scenarios are defined
- happy, edge, and failure paths are exercised where applicable
- permission boundaries are tested
- accessibility-sensitive scenarios are included for frontend work
- results map to acceptance criteria

## Fail Routing

Return to implementation, design, or requirements owner depending on the failure.
