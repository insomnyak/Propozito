# Goal-Driven Development Policy

Every project starts with a Project Purpose Contract. Every feature starts with a Feature Goal Contract.

## Required Before Planning

- target users
- user value
- system or business value
- non-goals
- risks
- success criteria
- unacceptable shortcuts

## Required Before Implementation

Every task must map to either:

- a user-facing goal, or
- a technical enabler required for a user-facing or system capability

Technical enabler tasks must state which capability they unblock. Work without clear user or system value must not proceed.
