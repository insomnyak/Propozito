# Terminology Profile

Propozito keeps canonical internal concepts, but user-facing labels should be configured instead of improvised by AI agents.

Canonical artifact: `.ai-state/terminology-profile.json`

Schema: `schemas/terminology-profile.schema.json`

Template: `templates/terminology-profile.json`

Supported presets may include Agile/Jira, Stage/Slice, PMBOK/WBS, Simple, or custom mappings. Reports, status pages, prompts, and handoffs should render the configured labels while preserving canonical IDs in machine-readable files.
