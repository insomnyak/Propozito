# Implementation Map

The implementation map is a stable subsystem inventory for AI coders and reviewers.

Canonical artifact: `.ai-state/implementation-map.json`

Schema: `schemas/implementation-map.schema.json`

Template: `templates/implementation-map.json`

It maps each subsystem to purpose, owned files, adjacent files, key tests, runtime routes, data ownership, state ownership, external dependencies, security boundaries, current status, known risks, and last verification time.

The relationship graph models edges. The implementation map summarizes subsystem ownership and operational context.
