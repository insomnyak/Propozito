# User Interaction Profile

The user interaction profile records how Propozito should communicate with the owner.

Canonical artifact: embedded in `.ai-state/setup-contract.json` or stored as `.ai-state/user-interaction-profile.json`

Schema: `schemas/user-interaction-profile.schema.json`

It may describe the owner as a systems architect, lead software engineer, experienced engineer, product manager, business stakeholder, nontechnical founder, or custom role. It should control completion-report depth, status wording, verification explanations, escalation format, and prompt-refinement output.
