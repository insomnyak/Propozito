# Persona Scenario QA Policy

Persona QA is scenario execution, not a code review.

Each persona scenario must define:

- role
- technical level
- permissions
- device or context
- primary goal
- secondary goal
- happy path
- edge path
- failure path
- accessibility considerations
- expected evidence

Persona QA agents must test like users: follow UI flows, check labels and error states, verify permission boundaries, record reproduction steps, and map results to acceptance criteria.
