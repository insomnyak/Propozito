# Framework Philosophy

The Propozito Orchestrator is built on the premise that AI agents, while powerful, require strict boundaries, verifiable evidence, and goal-oriented direction to produce reliable software.

## Core Tenets

1.  **Evidence Over Confidence**: Agents must prove their work through objective evidence (e.g., test results, command outputs), not just claim completion.
2.  **No Slop Code**: Placeholders, fake tests, and unverified assumptions are strictly prohibited.
3.  **Goal-Driven**: Every line of code must trace back to a defined user or business goal.
4.  **Persona-Validated**: Software must be tested from the perspective of diverse, realistic user personas.
5.  **Stateful Memory**: Project context is maintained centrally, not passed loosely between agents.
6.  **Human in the Loop**: Critical decisions and ambiguities require human escalation.
