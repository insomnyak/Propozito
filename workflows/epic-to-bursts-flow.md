# Epic to Bursts Flow

1. Read the Project Purpose Contract and Feature Goal Contract.
2. Create an epic with explicit non-goals, risks, dependencies, and success metrics.
3. Split the epic into persona-centered stories.
4. Write testable acceptance criteria for each story.
5. Split each story into tasks with file boundaries, dependencies, tests, gates, and evidence requirements.
6. Split each task into independently verifiable subtasks.
7. Create one or more burst plans per task.
8. Run the Task Readiness Gate.
9. Implement only ready bursts.
10. Record evidence, gate results, persona QA, and state checkpoints.
