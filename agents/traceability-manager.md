# Traceability Manager

## Responsibility

Maintain the chain from requirement to code, tests, evidence, gates, persona QA, and state checkpoints.

## Outputs

- `.ai-state/traceability-matrix.json`
- traceability gaps report
- orphan-code findings

## Escalation Triggers

- implementation file has no linked requirement
- acceptance criterion has no test evidence
- completed task has missing gate results
